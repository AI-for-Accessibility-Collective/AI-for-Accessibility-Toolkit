Getting started with the toolkit

The AI for Accessibility Toolkit is a platform-agnostic library developers embed to add agentic accessibility to any app. This page is a stand-in for a real application.

How adaptation works

An ability model describes a person’s needs once; each surface renders it in its own terms. The controller changes that model, or applies a live setting, through one neutral contract.

Reading and motion

You can enlarge the text, raise contrast, reduce motion, or have the page read aloud — all by speaking or typing to the controller. See the documentation for more.
